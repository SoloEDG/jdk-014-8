# PANEL

沉浸式漫画阅读器。支持导入整页图片、在浏览器内识别分镜框并审阅阅读顺序。

安装：`npm install`

本地启动：`npm run dev`

生产构建：`npm run typecheck && npm run build`

Docker 启动：`docker compose up --build`，访问 http://localhost:3014。

## 分镜框识别与审阅

导入一整页后，页面默认只有一个大格。点击工具栏的「识别分镜框」，浏览器会在本机
分析画面并在阅读区上方给出建议；**建议不会自动覆盖已有布局**，只有点「应用布局」
并在对照弹窗确认后才会写入。

- **识别精度**：`快速` 降采样、耗时少，但可能漏掉很窄的格子；`精细` 使用更高分辨率，
  能识别窄格，但更耗时、更占内存。可在审阅面板里随时切换并重新识别。
- **审阅时可继续阅读**：识别期间和结果就绪后都能翻阅、切换逐格模式、修改对白。
  识别在 Web Worker 中运行，不阻塞界面。
- **迟到结果与编辑对应**：结果带着识别开始时的页面修订号返回。若识别期间你改过对白、
  拖动过框线或排过顺序，迟到的建议只会补充未处理区域；已写的对白永远留在原来的那一格，
  即使整页被拆成多格，也只会迁移到与它重叠最大的新格并标记「待确认」。
- **不确定的结果**：斜线格、跨格人物、无边框画面会降低可信度并给出提示。此时可以
  「保留整页」、手动在画面上拖拽加框，或合并/拆分已有的框；可点「原布局」随时对照。
- **手动调整**：拖动框移动、四角缩放、方向键微调、数字徽标或 ↑↓ 调整阅读顺序；
  空白处拖拽或点「添加区域」加框；「合并」「上下/左右拆分」重划区域。
  「重新建议」按横向行带重排顺序。拆分时对白只跟重叠更大的一侧；合并时对白按顺序保留。
- **应用与迁移**：应用前会显示原布局与确认后布局的对照，并说明书签、声音触发点与
  当前镜头将如何迁移。迁移按区域归属：能落在新框内的直接用该框，否则取与旧框重叠最大
  的区域；引用不会丢失。取消、失败或关闭时不改动任何现有布局。
- **布局元数据**：每页记录 `layout.source`（whole / detected / manual）与修订号，
  用于判断迟到的结果与防止覆盖别处发生的修改。

实现位于 `src/features/detection/`：

- `lib/detector.ts`：纯函数分割（纹理/纸色分析 + 递归分隔带搜索），可在 Worker 或主线程运行。
- `lib/detector.worker.ts`：Worker 入口，支持取消。
- `lib/review.ts`：审阅框的拖动、缩放、合并、拆分、排序与迟到结果合并。
- `lib/apply.ts`：应用前的决策与内容迁移。
- `lib/image.ts`：绘制到工作分辨率（矢量图按页面尺寸渲染，避免细格线丢失）。
- `model/detection.ts`：会话状态、任务修订号、取消与失败处理。
- `ui/`：工具栏建议条、审阅面板、应用对照弹窗。
